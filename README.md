# WinboxV4_Session_Importer
Набор инструментов для конвертации старых сессий Winbox (`.wbx`) в формат JSON и их последующего автоматического импорта в Winbox v4 через графический интерфейс.

## 🛠️ Требования

Скрипты разработаны для **Linux**. Для корректной имитации ввода и работы с буфером обмена необходимо установить системные утилиты:

- **Arch Linux**: `sudo pacman -S xdotool xclip`
- **Debian/Ubuntu**: `sudo apt install xdotool xclip`

## 🚀 Быстрый старт

### 1. Подготовка окружения
Рекомендуется использовать виртуальное окружение Python:

```bash
python3 -m venv venv
source venv/bin/activate

2. Конвертация данных
Используйте wbx2json.py для извлечения данных из вашего бинарного файла сессий:
Bash
python3 wbx2json.py путь_к_файлу.wbx sessions.json
3. Настройка карты полей (TabMap.txt)
Файл TabMap.txt — это «карта» интерфейса Winbox v4. Скрипт использует её, чтобы понять, сколько раз нужно нажать Tab, чтобы попасть в нужное поле.
Структура файла:
    • Каждая строка должна начинаться с номера, за которым следует точка и название поля (например, 1. Connect to).
    • Скрипт автоматически вычисляет количество переходов между полями на основе этих номеров.
Пример:
    • 1. Connect to
    • 2. Login
    • 3. Password
    • 11. Group
    • 12. Comment
    • 13. Save to list
Если интерфейс программы изменится, просто обновите номера в этом файле.
4. Автоматический импорт
Важно: Во время работы скрипта не используйте мышь и клавиатуру.
    1. Запустите Winbox v4.
    2. Запустите скрипт импорта:
       Bash
       python3 create_sessions.py
    3. У вас будет 10 секунд, чтобы переключить фокус на окно Winbox и поставить курсор в поле Connect To.
🧠 Особенности скрипта
    • Умная проверка: Скрипт проверяет наличие xclip, xdotool и валидность файлов перед стартом.
    • Безопасность: Используется вставка через буфер обмена (Ctrl+V), что решает проблемы с раскладкой клавиатуры.
    • Обработка ошибок: Если одна запись не удалась, скрипт выведет ошибку, пропустит её и продолжит работу.
