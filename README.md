# WinboxV4_Session_Importer
Набор инструментов для конвертации старых сессий Winbox (`.wbx`) в формат JSON и их последующего автоматического импорта в Winbox v4 через графический интерфейс.

## Описание файлов проекта
**bx2json.py** - скрипт для извелчения сессия из адресной книги WinBox v3  
**import2WboxV4.py** - скрипт для импорта извлеченных сессий из адресной книги WinBox v3  
**requirements.txt** - требования для запуская скриптов  
**TabMap.txt** - описание интерфейса "TAB'ами"  
**readme.md** - файл документации  

## Требования

Скрипты разработаны для **Linux**. Для корректной имитации ввода и работы с буфером обмена необходимо установить системные утилиты:

- **Arch Linux**: `sudo pacman -S xdotool xclip`
- **Debian/Ubuntu**: `sudo apt install xdotool xclip`

## Быстрый старт

### 1. Подготовка окружения
Рекомендуется использовать виртуальное окружение Python:

```bash
python3 -m venv venv
source venv/bin/activate
```

### 2. Конвертация данных
Используйте wbx2json.py для извлечения данных из вашего бинарного файла сессий(Экспортируйте файл или укажите путь до текещей адресной книги winbox v3(*.wbx), на выходе файл c сессиями в формате json):

```Bash
python3 wbx2json.py путь_к_файлу.wbx sessions.json
```

### 3. Настройка карты полей (TabMap.txt)
Файл TabMap.txt — это «карта» интерфейса Winbox v4. Скрипт использует её, чтобы понять, сколько раз нужно нажать Tab, чтобы попасть в нужное поле. 

**Структура файла:**
* Каждая строка должна начинаться с номера, за которым следует точка и название поля (например, 1. Connect to).
* Скрипт автоматически вычисляет количество переходов между полями на основе этих номеров.

Пример:

```
1. Connect to
2. Login
3. Password
4. Remember password 
5. Workspase
6. RoMON Agent
7.
8. Connect
9. Connect to RoMON
10. Open in new
11. Group
12. Comment
13. Save to list
14. with password
15. Select from
16. Find
17. Filter
18. All
19. Show Menu
20.
21. Colum selection
22.
23.
24.
25. Live
26. Open new window app box 
27. Settings
```

**Если интерфейс программы изменится, просто обновите номера в этом файле.**

### 4. Автоматический импорт
> **ВАЖНО: Во время работы скрипта не используйте мышь и клавиатуру.**

Запуск ипморта:
1. Запустите Winbox v4.(Отключите "Filter" если он включен)
2. Запустите скрипт импорта:

```    Bash
       python3 create_sessions.py sessions.json
```   
3. У вас будет 15 секунд, чтобы переключить фокус на окно Winbox v4 и поставить курсор в поле "**Connect To**".
4. Если на экране появится запрос "An application is askinng for special privileges: Control input devices", необходимо ответить "Approve", далее вернуться в консоль и подтвердить готовность и вернуть фокус на первый элемент в поле  "**Connect To**".
5. Скрипт самостоятельно внесет все сессии в адресную книгу Winbox v4, вам останется только наблюдать за магией. 


### Особенности скрипта
* Умная проверка: Скрипт проверяет наличие xclip, xdotool и валидность файлов перед стартом.
* Безопасность: Используется вставка через буфер обмена (Ctrl+V), что решает проблемы с раскладкой клавиатуры.
* Обработка ошибок: Если одна запись не удалась, скрипт выведет ошибку, пропустит её и продолжит работу.
